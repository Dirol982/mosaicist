mosaicist.com: что ищут ваши клиенты

Рынок: СШАЯзык: английскийФокус: мозаика для бассейновАудитория: владельцы, архитекторы, дизайнеры

Главное, что показал анализ:

  1. На сайте нет страницы услуги «мозаика для бассейнов». Всё о бассейнах разбросано по проектам и главной. Google нечего показать по запросам вроде custom pool mosaics, поэтому эту страницу нужно сделать первой.
  2. Самый массовый спрос — на идеи и вдохновение (pool mosaic ideas, pool tile ideas, pool mural ideas). Такие запросы закрываются статьями в блоге со ссылками на услугу. Ваши 14 проектов — готовый материал для первой статьи.
  3. Люди ищут цену. Запросы про стоимость пишут, когда уже готовы заказывать. Нужна отдельная страница о том, из чего складывается цена, без конкретного прайса.
  4. Страницы проектов не работают на поиск. Заголовки вроде «Modern - Amorphous» не содержат ни слов «pool mosaic», ни города. Текст на каждой — около 170 слов. Достаточно переименовать и дописать.
  5. Сильные стороны, о которых сайт молчит: собственная смальта, византийская техника, работа с историческими домами Coral Gables. По этим темам есть устойчивый информационный спрос, а конкуренты их не закрывают.

Как оценивался спрос

Платных сервисов частоты (Google Keyword Planner, Ahrefs, Semrush) нет, поэтому спрос оценён по подсказкам Google для США. Чем меньше букв нужно набрать, чтобы Google сам предложил запрос, тем чаще его ищут. «Высокий» — запрос появляется после первой трети-половины фразы, «средний» — после двух третей, «низкий» — почти в конце, «—» — Google не подсказывает его вообще. Это сравнение запросов между собой, а не число поисков в месяц. Короткие общие запросы (например, pool mosaic) этот метод занижает, потому что после слова «pool» Google подсказывает много чужих тем. Приоритет поэтому учитывает не только спрос, но и ценность запроса для бизнеса. Когда на сайте заработает Google Search Console, через 2–3 месяца оценки можно заменить реальными цифрами.
